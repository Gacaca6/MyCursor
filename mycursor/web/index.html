Install MyCursor on your iPhone

Tap your browser’s Share button, then Add to Home Screen. Keep Open as Web App on if shown, then tap Add.

If Chrome does not show that option, open this page in Safari and use Share → Add to Home Screen.

Launch MyCursor from its new icon. Start the PC receiver using the MyCursor Phone Touchpad desktop shortcut. Both devices must be on the same Wi-Fi or hotspot.
